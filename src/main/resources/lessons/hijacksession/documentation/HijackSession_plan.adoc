= Hijack a Session

== Concept

Predictable session identifiers can let an attacker guess another user's active session. Secure
session identifiers need high entropy, server-side validation, a limited lifetime, and binding to
the authenticated account.

== Goals

Inspect the lesson's opaque session cookie and verify that guessed, expired, or cross-account
identifiers do not authenticate as another user. The fixed lesson does not provide a session
prediction exploit.
