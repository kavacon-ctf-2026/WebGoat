== Safe sorting for dynamic ORDER BY

Prepared statements bind values, but SQL identifiers such as column names cannot be bound as values. An application that offers sorting should map a small set of accepted sort keys to fixed column names.

The server list uses this pattern. Its API accepts only id, hostname, ip, mac, status, or description; any other sort expression is rejected. The page's sort controls use those keys, and the production server is included in the displayed list for the exercise below.
