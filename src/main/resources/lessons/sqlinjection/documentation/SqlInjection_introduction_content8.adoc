== Confidentiality: access only your own permitted data

SQL injection can expose private records when an application mixes request text with SQL. This form demonstrates a safer design: the application accepts the allowlisted account name `Smith`, binds the name and authentication TAN as values, and queries only John Smith's department.

Use your assigned authentication TAN. A successful request returns the department only; it does not return salary, TAN, or other employees' records. SQL text in either field is treated as a value and cannot broaden the query.
