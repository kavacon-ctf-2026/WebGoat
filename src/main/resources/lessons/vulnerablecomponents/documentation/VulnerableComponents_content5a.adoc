== Secure XML parsing

This exercise accepts an XML document containing a plain contact. The current implementation uses a hardened XML parser and does not use XStream.
[source,xml]
----
<contact>
    <id>1</id>
    <firstName>Bruce</firstName>
    <lastName>Mayhew</lastName>
    <email>webgoat@owasp.org</email>
</contact>
----

Submit this contact to complete the exercise. The parser permits only the `id`, `firstName`, `lastName`, and `email` scalar fields. It rejects DTDs, nested objects, class selectors, attributes, duplicate fields, and extra elements; XML input cannot select a Java type or invoke an object gadget.
