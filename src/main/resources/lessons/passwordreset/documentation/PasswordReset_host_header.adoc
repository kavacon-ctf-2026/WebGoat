== Creating the password reset link

Reset links are generated with a cryptographically secure random token, expire after 15 minutes,
and are consumed after a successful password change. The token is bound to the signed-in account.
The application builds links from its configured base URL and never trusts the request's `Host`
header. Reset requests for another user's address receive the same generic response and do not
create a usable token.

== Assignment

Request a reset for your own account at `<your username>@webgoat.org`, read the message in WebWolf,
open the link in your signed-in session, and set a new password. Reusing an expired, consumed, or
different user's link does not change any account.
