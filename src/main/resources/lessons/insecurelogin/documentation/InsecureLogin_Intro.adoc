
=== Concept
Credentials must be protected in transit with HTTPS and stored on the server as salted, adaptive password hashes. Client-side obfuscation does not protect credentials. This local lesson stores a hash for the signed-in WebGoat user; the deployment still needs TLS to protect form submissions.

=== Goals
* The user should understand that network traffic can expose credentials when TLS is absent
* The user should recognize that hiding credentials in JavaScript is not an authentication control
