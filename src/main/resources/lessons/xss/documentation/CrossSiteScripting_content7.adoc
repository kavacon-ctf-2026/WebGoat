== Stored XSS
Stored Cross-Site Scripting is different in that the payload is persisted (stored) instead of passed/injected via a link.

== Stored XSS Scenario
In a vulnerable application:
* An attacker posts script markup to a message board
* The message is stored in a server database
* A victim reads the message
* If the page inserts that message as HTML, the script may execute in the victim’s browser
** The script could steal sensitive information, like the session id, and release it to the attacker

In this patched exercise, comments are inserted as text, so stored markup is displayed but does not execute.

*Victim does not realize attack occurred*
